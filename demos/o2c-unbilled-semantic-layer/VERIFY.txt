Caveats for Mac
---------------
  * Use Python 3.11 or 3.12. Python 3.13 cannot install dbt-metricflow 0.11.0.
  * which mf must be .venv/bin/mf after `source .venv/bin/activate`.
  * Group-by names are ticket__sold_to / ticket__payer / ticket__terminal,
    not the bare words in the original brief.
  * mf may print a "new version 0.13.0 available" warning. Do not upgrade
    for this demo (0.13 wants dbt-core 1.10.4–1.12 and is a different line).
  * dbt 1.10 prints a deprecation banner; ignore it. We stayed off 1.12
    on purpose so the legacy YAML spec remains the one in this zip.
