LSC lineage portal: setup guide

This zip holds the code, the synthetic-data generator and the text2cypher chat portal for Lagos Refining & Supply Company (LSC), a fictional downstream refiner. It contains no data, no installed packages and no keys. Follow the steps below in order. Allow about an hour, most of it waiting on installs.

Commands are for Windows PowerShell. On macOS or Linux, use .venv/bin/python instead of .venv\Scripts\python.exe and forward slashes in paths.

  1. Install the prerequisites
  2. Unzip and install dependencies
  3. Fill in the settings file
  4. Create the Neo4j database
  5. Generate and load the data
  6. Start the backend and frontend
  7. Check the answers
  8. Run the tests (optional)
  9. Troubleshooting

This file holds your keys. Never commit, zip or email it.

4. Create the Neo4j database

Desktop or Enterprise only. In Neo4j Browser, switch to the system database and run:

CREATE DATABASE lsc IF NOT EXISTS WAIT;

On Community or Aura, skip this step and make sure the neo4j database is empty. The loader refuses a database that holds other data.

5. Generate and load the data

The generator is deterministic. It writes the same 45,426 nodes and 77,946 relationships into synthetic_data/ every time.

.venv\Scripts\python.exe src\generate_shareable_catalog.py
.venv\Scripts\python.exe src\verify_synthetic_catalog.py
Wrote 45426 nodes and 77946 relationships
[ok] profile  [ok] leaks  [ok] report lineage
.venv\Scripts\python.exe src\load_synthetic_catalog.py --database lsc
.venv\Scripts\python.exe src\verify_synthetic_catalog.py --database lsc
Database 'lsc' matches manifest: 45426 nodes, 77946 relationships
[ok] database  [ok] competency  [ok] database report lineage

Every line must say [ok] before you go on. Use --database neo4j on Community or Aura. Load soon after generating: the portal archives chat messages older than 30 days, which empties the feedback questions.

Optional: run the real Power BI loader

.venv\Scripts\python.exe src\load_powerbi_lineage.py --database lsc --source duckdb:///synthetic_data/source.duckdb

This reads the generated Power BI export the same way production does. The counts stay the same and verify still passes.

Open http://localhost:5173 and ask How many Gold tables are there? The answer is 43.

What a good answer looks like

Ask Trace wholesale_core.Margin_Fact back to its replica source. The chat names each hop, and the dashboard shows the same result three ways.

The e2e run needs the backend and Neo4j up. It asks all 16 questions above in the browser, calls your LLM about 25 times and takes about 9 minutes.

9. Troubleshooting

ProblemFix
uv or pnpm is not recognisedReopen the terminal after installing. For pnpm, run npm install -g pnpm first.
Refusing to load: the database holds other dataPoint --database at an empty database, or drop and recreate it.
Database does not match manifestA partial load or other data is in the way. Drop and recreate the database, then load again.
The portal answers about the wrong databaseSet NEO4J_DATABASE to the database you loaded and restart the backend.
LLM_PROVIDER is set but its key is emptyThe key for your provider is missing or still a placeholder.
OpenAI calls fail with a URL errorOPENAI_BASE_URL is set to an empty value. Comment it out unless you use a compatible service.
Feedback questions show nothingThe catalog was generated more than 30 days ago and its messages were archived. Generate and load again.
Port 8000 or 5173 is already in useStop the other copy, or run the backend with $env:PORT="8001" and the frontend with $env:VITE_BACKEND_URL="http://localhost:8001/ask"; pnpm dev --port 5174.
pnpm install fails on long pathsRun pnpm install --store-dir C:\pnpm-store.
An answer looks wrongLLM answers vary. Ask again and compare with the table in step 7. The Cypher tab shows exactly what ran.
