# Step 11: competency regression

The 44 competency questions (`../competency-questions.md`, locked 2026-09-18) are the ontology's acceptance test. EPM-DEC-001-0019 defines "all green": every question is answerable from the published release, or parked by a recorded decision. For questions 40 and 43, only the part the graph supplies is tested: every live concept has one definition (Q40 excludes the retired concept, the concept on implementation hold, and CM-1-1-3-5-3, the intentional business-evidence hold), and none has a second copy (Q43).

- `expected.csv` gives each question a status:
  - `answerable`: its queries run on the release.
  - `partial`: the graph part's queries run, and `waits_for` names the rest.
  - `waits:<step or decision>`: no query yet; `waits_for` says what the question needs.
- `queries/` holds one SPARQL file per tested part. The first line is the question. A query marked "(must be none)" must return zero rows; every other query must return at least one.
- `run.py` runs the queries against the release (default `../releases/core/2.1.0/core.ttl`) together with the organization module's vocabulary, roles and assignments, the kpi module's vocabulary and measures, the data-product module's vocabulary and data products, the value-stream module's vocabulary and value streams, the system module's vocabulary and systems, the lane module's vocabulary and lanes, the market-data module's vocabulary and series, the placement kinds, and the source tiers, and prints the coverage. `scripts/check.sh` runs it and `test_run.py`.

On core 2.1.0 with the organization, kpi, data-product, value-stream, system, lane and market-data modules, the placement kinds and the source tiers: 27 answerable, 4 partial (Q7, Q11, Q40, Q43), 13 waiting. The data-product module (EPM-DEC-001-0053) made Q7 partial; the value-stream module (EPM-DEC-001-0054) made Q10 answerable (Q7 stays partial until `core` 2.2.0 holds Loss Control's producer); the system module (EPM-DEC-001-0055) made Q6 answerable; the lane module (EPM-DEC-001-0056) made Q9 answerable. Q15 is answerable across the modules: when one word names more than one IRI, the graph says whether they are one thing or several. A retired IRI points to the one that replaces it (`dcterms:isReplacedBy`), as for the role names the decision owner merged (EPM-DEC-001-0045); a link such as `vs:realizes` says how two same-named things relate (a value-stream process realizes the map process of the same name); with neither, they are different things, told apart by their IRIs. On 2026-10-19, 61 words name more than one IRI, such as Finance (a process, a business domain and a data product line).
