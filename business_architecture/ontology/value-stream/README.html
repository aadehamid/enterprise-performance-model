The value-stream module brings the value-stream overlay into the ontology: the Commercial Hydrocarbon Lifecycle (../../business_process/value_stream_commercial_lifecycle.json) and Order to Cash (../../business_process/value_stream_order_to_cash.json). Each value stream has stages in sequence; each stage has value-stream processes; each value-stream process uses one capability, and may realize process-map processes by IRI (57 of the 58 did; all 58 since 2026-10-23, EPM-DEC-001-0090), produce or consume data products (20 of the 58 do), and carry cited measure links. The overlay references process nodes and never duplicates them (playbook, Step 7). It holds definitions only (EPM-DEC-001-0005). Its namespace is https://w3id.org/lsc/ontology/modules/value-stream/; its build reads core 2.4.0 (2.3.0 until 2026-10-26, EPM-DEC-001-0105; 2.2.0 until 2026-10-23, EPM-DEC-001-0089; 2.1.0 until 2026-10-22, EPM-DEC-001-0076), and it depends on the data-product module and the kpi module; its released 1.0.0 package requires core 2.2.0, 1.1.0 requires core 2.3.0 (EPM-DEC-001-0090), and 1.2.0 requires the current core, data-product and kpi releases (EPM-DEC-001-0106). EPM-DEC-001-0054 records the design.

Until 2026-10-22 the module was not released; a release needed the decision owner's approval. 2026-10-22: released as 1.0.0, with the decision owner's approval of the release plan (EPM-DEC-001-0077). The package is in ../releases/value-stream/1.0.0/. 2026-10-23: 1.1.0, with the decision owner's approval of the close-out releases, is in ../releases/value-stream/1.1.0/ (EPM-DEC-001-0090). 2026-10-26: 1.2.0, a minor Claude approved under the delegation, is in ../releases/value-stream/1.2.0/: the three measure relationships are top concepts both ways (EPM-DEC-001-0106).

Not carried over, by the schema's rule or EPM-DEC-001-0054: the gapAnalysis entries (documentation only), a flow's free-text note, each process's slide letter, and the files' domain as a core business-domain code (kept as written in vs:sourceDomain).
