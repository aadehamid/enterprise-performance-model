# Reference: APQC Process Classification Framework — Downstream Petroleum v7.2.2

`APQC-PCF-Downstream-Petroleum-v7.2.2.xlsx` is the official APQC Excel release
(Published May 30, 2025; 2,012 process elements across 13 categories).
It is used in this repo **only as a consistency reference** — the repo's own
business processes remain the source of truth for the model.

Source: https://www.apqc.org/resource-library/resource-listing/apqc-process-classification-framework-pcf-downstream-petroleum-1
