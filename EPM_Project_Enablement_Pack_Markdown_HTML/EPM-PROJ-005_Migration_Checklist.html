EPM Project Migration Checklist

A controlled checklist for moving the existing work into the dedicated project

Before migration

  • [ ] Confirm project name and owner.
  • [ ] Confirm project instructions limit and paste EPM-PROJ-001.
  • [ ] Gather all current EPM foundation Markdown files.
  • [ ] Gather the HTML reading package.
  • [ ] Gather KPI Store technical designs.
  • [ ] Gather relevant Tableau XML extraction outputs.
  • [ ] Gather current Power BI semantic-model and report inventory.
  • [ ] Gather existing data portfolio, value-stream, capability, and process artifacts.
  • [ ] Identify decisions that exist only in chat and are not yet captured.

Project upload

  • [ ] Upload EPM-FOUND-000.
  • [ ] Upload EPM-FOUND-000A.
  • [ ] Upload EPM-FOUND-001 through EPM-FOUND-006.
  • [ ] Upload EPM-PROJ-002 through EPM-PROJ-005.
  • [ ] Upload technical designs and domain artifacts.
  • [ ] Upload HTML package.
  • [ ] Verify filenames and versions.

Project initialization

  • [ ] Run the onboarding prompt.
  • [ ] Confirm the project recognizes the working baseline.
  • [ ] Generate an artifact inventory.
  • [ ] Generate a contradiction and gap register.
  • [ ] Confirm the first three work packages.
  • [ ] Create focused chats only as work begins.

Knowledge validation

  • [ ] Ask the project to explain the business architecture.
  • [ ] Ask it to classify sample measurements, metrics, and KPIs.
  • [ ] Ask it to explain semantic model versus ontology.
  • [ ] Ask it to explain foundational versus derived products.
  • [ ] Ask it to identify where a reusable calculation should live.
  • [ ] Ask it to trace Gasoline Netback CPG end to end.

Ongoing governance

  • [ ] Record major decisions as ADRs.
  • [ ] Update canonical artifacts after accepted changes.
  • [ ] Update version and status.
  • [ ] Maintain the Master Index.
  • [ ] Do not let working-chat conclusions silently become standards.
  • [ ] Periodically review for duplicate or contradictory artifacts.
  • [ ] Retire superseded documents explicitly.
